Put your University of Lahore photos in this folder, using these exact file names (.jpg):

HERO (circular collage on the home page)
  uol-1.jpg   large centre circle   -> main campus building or gate
  uol-2.jpg   top-right circle      -> students on campus
  uol-3.jpg   small overlapping one -> library, class or lawn
  uol-4.jpg   bottom-left circle    -> auditorium or sports ground

CATEGORY CARDS AND EVENT CARDS
  seminar.jpg       -> a seminar or guest talk
  workshop.jpg      -> a workshop or lab session
  sports.jpg        -> a sports match or ground
  competition.jpg   -> a hackathon, debate or award ceremony

Tips: landscape photos about 1200x800 work best for the four category photos,
and roughly square photos (at least 800x800) for the hero circles.
Until a file exists, the site shows a coloured placeholder or the old illustration.
